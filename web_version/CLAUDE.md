# CLAUDE.md (web_version)

브라우저에서 손글씨 숫자를 인식하는 웹 버전입니다. **외부 라이브러리 없이 순수 자바스크립트로 추론**하며, 빌드 과정 없이 GitHub Pages에 정적 파일로 올립니다. 루트 `CLAUDE.md`의 공통 규칙을 따릅니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구성. 맨 위 학번·이름 표시줄, 그림판, 결과 영역. 스크립트를 그림판 → 전처리 → 모델 → 앱 순서로 불러옵니다. |
| `스타일.css` | 화면 스타일 (`index.html`, `검증.html` 공용, 밝은/어두운 화면) |
| `그림판.js` | 캔버스 그리기 (포인터 이벤트로 마우스 + 터치). 검은 배경에 흰 글씨. `그림판.그림판_만들기()` |
| `전처리.js` | `app.py`의 `전처리()` 이식. PIL LANCZOS 리샘플링(22비트 고정소수점)과 파이썬 `round()`(짝수 반올림)까지 그대로 구현해 파이썬과 같은 값을 냅니다. `전처리.전처리하기()` |
| `모델.js` | 가중치 적재 + 순전파. 합성곱(3x3, 패딩 1)·ReLU·2x2 최대풀링·전결합. `모델.모델_불러오기()` |
| `앱.js` | 위 셋을 엮어 붓을 뗄 때마다 인식하고 예측·신뢰도·확률 막대를 표시 |
| `가중치.bin` | 산출물. 텐서 12개(합성곱 4개 + 전결합 2개의 weight/bias, 배치정규화는 합성곱에 합침)를 float32 리틀 엔디언으로 이어 붙인 데이터 (약 3.5MB) |
| `가중치정보.json` | 산출물. 층 순서, 텐서 이름·형상·오프셋, 정규화 상수(평균, 표준편차) |
| `검증.html` | 파이썬 결과와 대조하는 검증 페이지 (로컬 전용) |

- `가중치.bin`, `가중치정보.json`은 `python desktop_version/가중치내보내기.py`가 만듭니다. 직접 고치지 않습니다. **재학습하면 반드시 다시 실행**합니다.
- `전처리.js`, `모델.js`는 Node.js에서도 `require`로 불러올 수 있습니다 (브라우저에서는 `window.전처리`, `window.모델`).

## 검증

```bash
python desktop_version/검증데이터만들기.py   # web_version/검증데이터.json/.bin 생성 (.gitignore로 제외, 약 16MB)
python -m http.server 8000                  # 저장소 루트에서 실행 → http://localhost:8000/web_version/검증.html
```

- MNIST 테스트 이미지를 280x280으로 키워 파이썬(`app.py` 전처리 + PyTorch)과 자바스크립트로 각각 처리해 대조합니다.
- 측정값 (200장): 전처리 결과 200/200 일치(최대 차이 7e-7), 예측 200/200 일치(점수 최대 차이 5e-6), 정확도 200/200, 한 장 약 50ms.
- `file://`로 열면 `fetch`가 막히므로 반드시 로컬 서버로 엽니다.

## 배포와 주의

- GitHub Pages는 `main` 브랜치 루트를 배포하고, 루트 `index.html`이 이 폴더로 이동시킵니다. 폴더 이름·위치를 바꾸면 루트 `index.html`의 이동 경로도 고칩니다.
- 외부 CDN·라이브러리를 추가하지 않습니다. 필요한 계산은 직접 구현합니다.
- 정규화 상수는 `가중치정보.json`에서 읽습니다. 자바스크립트에 적지 않습니다.
- 페이지 맨 위 "학번 2601953 이름 안서연" 표시줄은 과제 요구사항이므로 지우지 않습니다.

# CLAUDE.md (web_version)

데스크톱 버전이 내보낸 가중치로 손글씨 숫자를 인식하는 정적 웹 앱입니다. 외부 라이브러리·CDN·빌드 도구 없이 순수 자바스크립트로 추론하고 GitHub Pages에 배포합니다. 루트 `CLAUDE.md`의 공통 규칙을 따릅니다.

## 로컬에서 열기

`fetch`로 가중치를 읽으므로 파일을 더블클릭(`file://`)하면 동작하지 않습니다. 저장소 루트에서 `python -m http.server 8000`을 실행하고 http://localhost:8000/web_version/ 을 엽니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html`, `스타일.css` | 화면 (맨 위 학번·이름, 그림판, 결과) |
| `그림판.js` | 280x280 캔버스, 마우스·터치·펜 (두 번째 손가락과 오른쪽 버튼 무시) |
| `전처리.js` | `desktop_version/app.py`의 `전처리()`와 같은 계산 (Pillow LANCZOS, 파이썬 `round()`) |
| `모델.js` | `가중치정보.json` + `가중치.bin`을 읽어 순전파 |
| `앱.js` | 붓을 떼면 전처리 → 추론 → 예측·신뢰도·확률 막대 |
| `가중치.bin`, `가중치정보.json` | `desktop_version/가중치내보내기.py`의 산출물. 직접 고치지 않습니다 |
| `검증.html` | 파이썬 결과와 대조하는 검증 페이지 |

## 파이썬과 맞춰야 할 지점

- 전처리: 여백 자르기, `round(가로 * 20 / 긴변)`(최소 1), Pillow LANCZOS(22비트 고정소수점, 가로 먼저), `(28 - 크기) // 2` 배치, 무게중심 이동량 `round(14 - 중심)`(짝수 반올림), `(값/255 - 평균) / 표준편차`.
- 모델: `가중치정보.json`의 층 순서대로 계산합니다. 모델 구조를 바꾸면 `모델.js`가 그 층을 계산할 수 있는지 확인합니다.
- 정규화 상수는 `가중치정보.json`에서 읽습니다 (자바스크립트에 직접 적지 않음).

## 검증 절차

1. `python desktop_version/검증데이터만들기.py`로 `검증데이터.json`/`.bin`을 만듭니다 (git 제외).
2. 로컬 서버로 `검증.html`을 열어 순전파 일치, 전처리 일치, 예측 일치, 전체 정확도가 모두 "통과"인지 봅니다.
3. 또는 저장소 루트에서 `NODE_PATH="$(npm root -g)" node 검사/웹_검사.cjs`로 같은 검사와 화면 검사를 한 번에 돌립니다.
